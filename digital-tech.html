數位科技概論學習作業

本頁面記錄《數位科技概論》課程中的 HTML 與 CSS 實作練習與小作業成果。

HTML 活動作業 (01-04)

  • 活動 01 文字層級：科學活動介紹頁（練習標題層級、段落與上下標標籤）。
  • 活動 02 多媒體：校園自然觀察任務卡（練習圖片 `img`、聲音 `audio` 與影片 `video`）。
  • 活動 03 清單與表格：社團活動準備頁（練習 `ul`、`ol` 清單與 `table` 表格欄位）。
  • 活動 04 表單元件：社團體驗表（練習文字輸入框、單選/複選按鈕與下拉選單）。

CSS 活動練習 (05-09)

  • 活動 05 風格美化：色彩實驗室與視覺風格調整。
  • 活動 06 排版佈局：網頁版型區域配置（單欄、兩欄、側欄設計）。
  • 活動 07 卡片排列：Flexbox 網頁卡片排版與圖片裁切。
  • 活動 08 RWD 響應式：使用 `@media` 實現電腦版與手機版版型切換。
