數位科技概論學習作業

本頁面記錄《數位科技概論》課程中的 HTML 與 CSS 實作練習與小作業成果。

HTML 活動作業 (01-04)

活動 01 文字層級： 水與生活：小小科學探索日 活動 02 多媒體： 校園自然觀察任務卡 活動 03 清單與表格： 紙橋挑戰社：活動準備頁 活動 04 表單元件： 放學後社團體驗表

CSS 活動練習 (05-09)

活動 05 風格美化： 色彩實驗室與視覺風格調整。
活動 06 排版佈局： 網頁版型區域配置（單欄、兩欄、側欄設計）。
活動 07 卡片排列： Flexbox 網頁卡片排版與圖片裁切。
活動 08 RWD 響應式： 使用 @media 實現電腦版與手機版版型切換。
活動 09 無障礙設計： WAVE 機檢修正（對比度提升與 label 標籤配對）。
